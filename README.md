# js-puzzle
08/2026 Andy's Walk\
Think of the original ball as a tetrahedron dice. Label the home face 1, and the rest 2, 3, 4, roll the dice across the plane and you will get a equilateral triangle grid,\
with the each grid labeled with the number projected from the dice.\
As the length of the walk approaches infinity, Andy will eventually either find out something's wrong, or get back home and realize nothing. i.e., he'll eventually reach a 1 on the triangle grid.\
Back Home Condition:\
-back to the origin\
Realize Abnormality Condition:\
-reach a 1 that is not the origin
